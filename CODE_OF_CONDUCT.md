# Code of conduct

## The short version

Be respectful. Assume good faith. Critique code and ideas, not people.

## Expected behavior

- Give feedback that is specific and actionable. "This has a race condition when two reviewers
  edit the same draft" is useful; "this is wrong" is not.
- Accept feedback the same way. A review that finds a problem has done its job.
- Respect differing levels of experience, and remember that everyone was new to something once.
- Disagree about technical decisions in the open, and record the outcome — that is what the ADRs
  are for.

## Unacceptable behavior

- Harassment, discrimination, or personal attacks of any kind.
- Sexualized language or imagery, and unwelcome attention of any kind.
- Publishing others' private information without explicit permission.
- Sustained disruption of discussions.
- Anything else that would reasonably be considered inappropriate in a professional setting.

## Scope

This applies in every project space — issues, pull requests, discussions, and any public
communication about the project.

## Enforcement

Report unacceptable behavior by opening an issue or contacting the maintainer directly. Reports
are handled confidentially and reviewed as promptly as possible.

Maintainers may edit, remove, or reject any contribution that does not align with this code, and
may temporarily or permanently ban any contributor for behavior they judge inappropriate.
